# Lunara - Moonlit Emotional Journal

A private moonlit diary web app for writing personal diaries, organizing pages, and sharing selected diaries only with trusted readers using Lunara ID.

## Features

- Private diary creation
- Page-based diary writing
- Diary title and page title separation
- Profile image crop flow
- Private diary image storage with signed URLs
- Shared diaries
- Find People by exact Lunara ID
- Supabase Auth and database
- Moonlit celestial UI theme

## Tech Stack

- React
- Vite
- TypeScript
- Tailwind CSS
- Supabase

## Privacy

Lunara is private-first. Diaries are not public posts, and sharing is only done with trusted users through Lunara ID.
